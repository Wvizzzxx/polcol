# 🏛️ Владимирский политехнический колледж — Сайт

> Официальный сайт ГАПОУ Владимирской области «Владимирский политехнический колледж» (ВПК).

---

## 🛠 Стек технологий

### Фронтенд

| Технология | Версия | Назначение |
|---|---|---|
| **React** | 19.2.x | Основной UI-фреймворк (SPA) |
| **Vite** | 8.0.x | Сборщик проекта и dev-сервер |
| **Tailwind CSS** | 4.3.x | Утилитарный CSS-фреймворк (через `@tailwindcss/vite` плагин) |
| **React Router DOM** | 7.15.x | Клиентская маршрутизация (SPA-роутинг) |
| **Framer Motion** | 12.40.x | Библиотека анимаций и переходов между страницами |
| **@tabler/icons-react** | 3.44.x | Набор SVG-иконок (150+ компонентов) |

### Инструменты разработки

| Инструмент | Назначение |
|---|---|
| **ESLint** | Линтер JavaScript/JSX |
| **eslint-plugin-react-hooks** | Проверка правил хуков React |
| **eslint-plugin-react-refresh** | Проверка корректности React Refresh (HMR) |
| **@vitejs/plugin-react** | Плагин React для Vite (на базе Oxc) |

### Бэкенд / БД

Проект является **статическим SPA-приложением без серверной части**. Все данные (контент страниц, навигация, новости) хранятся в JavaScript-модулях на клиенте. Бэкенд/БД отсутствуют — сайт разворачивается как статический набор файлов (nginx, Apache, Vercel, Netlify и т.д.).

### Шрифты и оформление

- **Montserrat** — основной шрифт ( sans-serif )
- **Manrope** — шрифт заголовков ( display )
- Цветовая палитра: глубокие синие тона (`official` — `#1a365d`) + золотой акцент (`accent` — `#c5a55a`) — государственный/официальный стиль

## 🖼 Описание интерфейса

### Главная страница
- **Hero-секция**: тёмный фон с градиентом (official-900), декоративные анимированные круги (blur), заголовок «Владимирский политехнический колледж» с золотым текстовым градиентом, фото колледжа, CTA-кнопки «Поступить к нам» и «О колледже»
- **Карточки навигации**: 4 карточки (Абитуриентам, Студентам, Родителям, Сотрудникам) с градиентными иконками и hover-эффектами
- **О колледже**: двухколоночная секция с фото и текстом, статистика (80+ лет, 12 специальностей, 95% трудоустройство)
- **Направления обучения**: сетка 3×2 с карточками специальностей, эмодзи-иконками и кодами специальностей
- **Жизнь колледжа**: 3 карточки новостей с фото (учебный процесс, добрые дела, кампус)

### Шапка (Header)
- Фиксированная (`fixed top-0`), белый фон с тенью при скролле
- Лента российского флага сверху (4px: белый-синий-красный) — государственный стиль
- Логотип + название колледжа
- Кнопка «Версия для слабовидящих» (заглушка)
- Кнопка «Контакты»
- Десктопное горизонтальное меню с выпадающими подменю (hover)
- Бейдж «IT-Куб» с иконкой робота
- **Мобильное меню**: полноэкранное выдвижное с анимацией (AnimatePresence), раскрывающиеся подменю, дополнительные ссылки

### Новости
- Hero-секция с заголовком и описанием
- Фильтр по категориям (кнопки)
- Сетка новостей 2×N с тегами, датами и превью текста

### О колледже
- Hero-секция с описанием
- Миссия и ценности (двухколоночная сетка)
- Историческая хронология (1944→2024) — таймлайн с точками и карточками поочерёдно слева/справа
- Фотогалерея (5 фото в адаптивной сетке)
- Слово директора (карусель/блок с цитатой)
- Администрация (сетка карточек)
- Статистика (сетка 4×2)
- Ссылки на подразделы
- Блок лицензии и аккредитации

### Подстраницы (SubPage)
- Универсальный шаблон для 100+ страниц
- Hero-секция с уникальным цветовым градиентом для каждого раздела:
  - Сведения — синие тона
  - Абитуриентам — изумрудные тона
  - Студентам — бирюзовые тона
  - Родителям — янтарно-оранжевые тона
  - Сотрудникам — фиолетовые тона
  - IT-Куб — голубые тона
- Хлебные крошки (breadcrumbs)
- 4 типа блоков контента: `text`, `list`, `info`, `cards`
- Навигация по содержанию раздела
- Кнопка «На главную»

### Контакты
- Hero-секция с градиентным фоном
- Карточки контактов (адрес, телефон, email, режим работы)
- Форма обратной связи (имя, email, сообщение)

### Footer
- Тёмный фон (`official-800`), декоративная полоса сверху
- Логотип + описание учреждения
- Режим работы (Пн-Пт 8:00–17:00, Сб 8:00–14:00)
- Социальные сети: VK, Сферум, Telegram, OK

- Яндекс.Карта (iframe) с адресом
- Контактная информация: email, телефон, адрес, приёмная комиссия
- Копирайт: © 2017–2026 Министерство образования Владимирской области
- Ссылки: Политика конфиденциальности, Карта сайта

### Мобильная версия
- Адаптивная верстка на всех страницах (Tailwind: `sm:`, `md:`, `lg:`)
- Гамбургер-меню с анимированным выдвижным списком

## 🔑 Особенности

### 🎨 Дизайн-система
- **Официальный/государственный стиль**: глубокие синие тона + золотой акцент
- **Цветовая палитра**: определена через CSS Custom Properties в `@theme` (Tailwind v4)
- **Кастомные CSS-классы**: `.card-official`, `.btn-official`, `.btn-accent`, `.badge-official`, `.text-gradient`, `.official-pattern`, `.flag-stripe`
- **Российская символика**: декоративная полоса российского флага в шапке

### 🎭 Анимации (Framer Motion)
- Плавные переходы между страницами (`AnimatePresence mode="wait"`)
- Scroll-triggered анимации (`whileInView`)
- Параллакс-эффекты на hero-секциях
- Hover-эффекты на карточках (scale, translateY)
- Анимированные фоновые элементы (blur-круги)

### 📱 Адаптивность
- Полностью адаптивный дизайн (mobile-first)
- Мобильное меню с анимацией
- Адаптивные сетки (1→2→3→4 колонки)
- Стилизованный скроллбар

### 🗂 Универсальный шаблон страниц
- Компонент `SubPage` автоматически отображает контент для ~100+ маршрутов
- Контент определяется по пути URL из `pagesContent.js`
- 4 типа секций: текст, списки, информационные карточки, карточки с иконками
- Автоматические хлебные крошки
- Цветовая тема определяется по разделу пути

### 🎯 Система иконок
- Маппинг **150+ эмодзи → Tabler Icons** через утилиту `EmojiIcon`
- Все иконки навигации, контента и UI используют SVG-компоненты Tabler Icons
- Fallback на оригинальное эмодзи, если иконка не найдена

### 📍 Маршрутизация
- Клиентская маршрутизация через React Router v7
- **~150 маршрутов** определены в `App.jsx`
- Вложенные маршруты с общей обёрткой `Layout`
- Catch-all маршрут (`*`) для 404

### 📊 SEO-оптимизация
- `sitemap.xml` — карта сайта для поисковых систем
- `robots.txt` — правила индексации
- `.htaccess` — серверные правила (для Apache)

### 🌐 Социальные сети
- Ссылки на VK, Сферум, Telegram, Одноклассники в футере

### 🗺 Интеграции
- **Яндекс.Карта** (iframe) в футере для отображения расположения колледжа
- **Форма обратной связи** на странице контактов (前端-форма, без серверной обработки)

### ♿ Доступность
- Кнопка «Версия для слабовидящих» в шапке (заглушка)
- Семантическая разметка (`<nav>`, `<main>`, `<footer>`, `<section>`)
- ARIA-атрибуты (`aria-label="Меню"`, `aria-label="Breadcrumb"`)
- Уникальные `key` для списков
- `alt`-тексты для изображений

### 🚀 Деплой
- Сборка: `npm run build` → папка `dist/`
- Превью: `npm run preview` — локальный предпросмотр сборки
- `.htaccess` для Apache (SPA fallback)
- Совместим с Vercel, Netlify, GitHub Pages, любым статическим хостингом
